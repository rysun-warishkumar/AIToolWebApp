# SEO, Search Console & AI Search Setup

Production domain: **https://freeaitools.wtechnology.in**

## What the project includes

| Feature | Location |
|---------|----------|
| Central keywords & page copy | `frontend/src/config/seo.js` |
| Site brand & URL | `frontend/src/config/site.js` |
| Meta tags, Open Graph, JSON-LD | `frontend/src/components/seo/Seo.jsx` |
| `robots.txt`, `llms.txt`, static sitemap | Generated by `frontend/scripts/generate-seo-assets.mjs` on `npm run build` |
| Dynamic sitemap (tools, prompts, articles) | `GET /sitemap.xml` on Node backend |

## Nginx — sitemap (choose one)

### Option A — Dynamic sitemap (recommended)

The backend builds the sitemap from the database on every request. Add **above** the React `location /` block:

```nginx
location = /sitemap.xml {
    proxy_pass http://127.0.0.1:3001/sitemap.xml;
    proxy_set_header Host $host;
}
```

After deploy, verify:

```bash
curl -I https://freeaitools.wtechnology.in/sitemap.xml
# Expect HTTP 200 and many URLs (not just 9)
```

If you see **500**, pull latest code and restart PM2 (see deploy steps below). Ensure `APP_URL=https://freeaitools.wtechnology.in` is in `backend/.env`.

### Option B — Static sitemap (fallback)

If you do not proxy to Node, `npm run build` copies `frontend/public/sitemap.xml` into `dist/`. Refresh it before building:

```bash
cd frontend
npm run export-sitemap   # pulls live tools, prompts, articles from API
npm run build
```

## Deploy to live server (Utho VPS)

SSH into the server, then:

```bash
cd /var/www/ai-tools
git pull origin main

# Backend
cd backend
npm install --omit=dev
pm2 restart ai-tools-api

# Frontend (regenerates robots.txt, llms.txt, sitemap.xml, then builds)
cd ../frontend
npm install
npm run build

# Reload Nginx
sudo kill -HUP $(pgrep -f "nginx: master" | head -1)
```

**Verify after deploy:**

```bash
curl -s https://freeaitools.wtechnology.in/api/health
curl -s https://freeaitools.wtechnology.in/sitemap.xml | head -20
```

**Submit to Google Search Console:** `https://freeaitools.wtechnology.in/sitemap.xml`

When you add or update tools/articles in the admin panel, the **dynamic** sitemap updates automatically. With the **static** fallback, run `npm run export-sitemap && npm run build` on the server after major content changes.

## Google Search Console

1. Go to [search.google.com/search-console](https://search.google.com/search-console)
2. Add property: `https://freeaitools.wtechnology.in`
3. Verify via DNS TXT or HTML file in `frontend/public/`
4. Submit sitemap: `https://freeaitools.wtechnology.in/sitemap.xml`
5. Request indexing for `/`, `/tools`, `/prompts`, `/learning`

## Google Analytics 4

1. Create a GA4 property and web stream for your domain
2. Add to `frontend/index.html` inside `<head>`:

```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

3. Link GA4 to Search Console in Admin → Product links

## AI search (ChatGPT, Gemini, Perplexity, Google AI)

- **`/llms.txt`** — machine-readable site summary (auto-generated on build)
- **`robots.txt`** — allows GPTBot, ClaudeBot, PerplexityBot, Google-Extended, etc.
- **JSON-LD** — Organization, WebSite, FAQ, Article, SoftwareApplication schemas
- **FAQ section** on homepage — visible + FAQPage schema
