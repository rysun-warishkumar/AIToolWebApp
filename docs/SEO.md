# SEO, Search Console & AI Search Setup

Production domain: **https://freeaitools.wtechnology.in**

## What the project includes

| Feature | Location |
|---------|----------|
| Central keywords & page copy | `frontend/src/config/seo.js` |
| Site brand & URL | `frontend/src/config/site.js` |
| Meta tags, Open Graph, JSON-LD | `frontend/src/components/seo/Seo.jsx` |
| `robots.txt`, `llms.txt`, static sitemap | Generated by `frontend/scripts/generate-seo-assets.mjs` on `npm run build` |
| Dynamic sitemap (tools, prompts, articles) | `GET /sitemap.xml` on Node backend |

## Nginx — dynamic sitemap (recommended)

Add **above** the React `location /` block in your site config:

```nginx
location = /sitemap.xml {
    proxy_pass http://127.0.0.1:3001/sitemap.xml;
    proxy_set_header Host $host;
}
```

Reload Nginx after deploy. This exposes every published tool, prompt, and article to Google.

## Google Search Console

1. Go to [search.google.com/search-console](https://search.google.com/search-console)
2. Add property: `https://freeaitools.wtechnology.in`
3. Verify via DNS TXT or HTML file in `frontend/public/`
4. Submit sitemap: `https://freeaitools.wtechnology.in/sitemap.xml`
5. Request indexing for `/`, `/tools`, `/prompts`, `/learning`

## Google Analytics 4

1. Create a GA4 property and web stream for your domain
2. Add to `frontend/index.html` inside `<head>`:

```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

3. Link GA4 to Search Console in Admin → Product links

## AI search (ChatGPT, Gemini, Perplexity, Google AI)

- **`/llms.txt`** — machine-readable site summary (auto-generated on build)
- **`robots.txt`** — allows GPTBot, ClaudeBot, PerplexityBot, Google-Extended, etc.
- **JSON-LD** — Organization, WebSite, FAQ, Article, SoftwareApplication schemas
- **FAQ section** on homepage — visible + FAQPage schema
